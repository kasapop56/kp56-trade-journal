Both panels render the same sample dataset (87 trades). The left panel mimics today's behavior: one fetch pulls every row, all filtering happens in memory. The right panel mimics Part A: 10 rows per request (production will be 50), filters re-query Supabase with pushdown, "Load more" fetches the next page. Interact with both — change filters, scroll, click "Load more" — and watch the simulated network trace at the bottom of each panel.

CURRENT Loads all 87 rows up-front

On first open → fetchAllPaged('trade_ideas') + fetchAllPaged('mt5_trades') in parallel. Filters mutate historyCache in memory — no network. With 3,721 rows today, every visit downloads ~1 MB of JSON and parses 3,721 trade cards.
